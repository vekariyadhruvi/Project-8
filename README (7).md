# NumPy Analyzer

## Description
NumPy Analyzer is a Python-based menu-driven program that allows users to perform various operations on NumPy arrays. It supports creation and manipulation of 1D, 2D, and 3D arrays along with multiple analytical features such as mathematical operations, sorting, filtering, and statistical calculations.

## Features

### 1. Array Creation
- Create 1D, 2D, and 3D arrays
- User-defined input for elements and dimensions

### 2. Indexing and Slicing
- Access elements using indexing
- Perform slicing on all array types

### 3. Mathematical Operations
- Addition, subtraction, multiplication, and division
- Dot product
- Matrix multiplication

### 4. Combine and Split
- Combine arrays using concatenation
- Split arrays into multiple parts

### 5. Search, Sort, and Filter
- Search elements using conditions
- Sort arrays in ascending and descending order
- Filter elements based on conditions

### 6. Aggregates and Statistics
- Sum, mean, median, standard deviation, variance
- Minimum, maximum, percentile
- Correlation coefficient between arrays

## Technologies Used
- Python
- NumPy Library

## How to Run

1. Install NumPy (if not installed):
   pip install numpy

2. Run the Python file:
   python filename.py

3. Follow the menu options displayed in the terminal.
